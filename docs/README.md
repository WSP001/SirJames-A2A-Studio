# Sir James Adventures Book 003 - Documentation

## Overview

Sir James Adventures Book 003 is an interactive story application built with TypeScript and Vite. Players follow Sir James, a brave knight with blue eyes, and his companion Sparky the squirrel through enchanted adventures where choices matter.

## Key Features

- **Interactive Storytelling**: Choose your path with virtue-based decisions
- **Character-Driven**: Follow Sir James and Sparky through their adventures
- **Schema Validation**: JSON Schema v3.0 ensures story integrity
- **TypeScript**: Full type safety and excellent developer experience
- **Modern Build**: Vite for fast development and optimized production builds

## Project Structure

```
├── src/                    # Source code
│   ├── components/         # Story engine and UI components
│   ├── types/             # TypeScript type definitions
│   ├── validators/        # Story validation logic
│   └── main.ts           # Application entry point
├── schemas/               # JSON schema definitions
├── stories/              # Story content (JSON files)
├── scripts/              # Validation and utility scripts
├── tests/                # Test files
└── docs/                 # Documentation
```
