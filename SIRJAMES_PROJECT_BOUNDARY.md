## Not Allowed As Sir James Canon

- SeaTrace folders, repos, APIs, dashboards, supply-chain language, or seafood imagery.
- World Seafood Producers business folders or marketing claims.
- SirTrav business/application code unless a generic UI pattern is copied and renamed for Sir James.
- ROI, live API, detection, token auth, integration, or enterprise claims on public Sir James book pages unless they are actually implemented and verified for Sir James.
- Legacy code treated as production without current validation.

## Reuse Rule

Preserve the ideas, not the implementation.

Allowed reuse:

- Story structure.
- Child-friendly interaction patterns.
- Parent dashboard workflow vocabulary.
- Accessibility rules.
- Character consistency rules.
- Audio/image naming patterns.
- QA and release checklists.

Not allowed reuse:

- Raw secrets.
- Unverified API claims.
- Business metrics.
- SeaTrace or SirTrav identity.
- Old generated assets that contradict the character bible.
